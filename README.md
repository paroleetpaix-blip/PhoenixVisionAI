# Phoenix Vision AI

## Société

Phoenix Security Technologies

## Slogan

L'innovation au service de la protection.

## Description

Phoenix Vision AI est une plateforme intelligente de vidéosurveillance destinée à améliorer la sécurité routière grâce à l'intelligence artificielle.

Fonctions prévues :

- Détection automatique des véhicules
- Lecture des plaques d'immatriculation
- Alertes sur véhicules recherchés
- Tableau de bord intelligent
- Analyse du trafic
- Historique des événements

Développé par :

Phoenix Security Technologies
